About this app

This web page reads the RDTech TC66C USB-C power meter in your browser. It uses the Web Serial API, so it needs no install and no server. You connect the meter over USB and see the live values, the stored recording and a battery test.

  • Meter page shows live voltage, current, power and more, with charts.
  • Battery test page records a discharge and computes the capacity of a power bank.
  • The app is a Progressive Web App (PWA). You can install it and use it offline.

The device

Quick start

  1. Connect the meter to the computer with a USB cable.
  2. Open the app in Chrome or Edge (or Firefox 151+).
  3. Close other programs that use the port.
  4. Go to the Meter page and click Connect.
  5. Select "GD32 Virtual Com Port" in the browser dialog.

On the Meter page, each value has a small ? button that explains it.
