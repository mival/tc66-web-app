This browser has no Web Serial API. Use Chrome or Edge (or Firefox 151+), and open the page from a local file or from localhost/https.

Connection

Bluetooth: pair the supply in the system settings first (PIN usually 1234). Then select its Bluetooth COM port (outgoing) or its RFCOMM entry. Close the phone app, because the module accepts only one connection. The baud rate and the slave address must agree with the settings on the supply.
