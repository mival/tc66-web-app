Connection

Bluetooth: pair the supply in the system settings first (PIN usually 1234). Then select its Bluetooth COM port (outgoing) or its RFCOMM entry. Close the phone app, because the module accepts only one connection. The baud rate and the slave address must agree with the settings on the supply.

Memory groups (M0–M9)

Recall loads the voltage, current and protection values of a group. Edit changes the values of a group on the supply. M0 is the active group: the supply loads it at power on, and a change on the supply also writes into M0.

GroupU (V) I (A) OVP (V) OCP (A) OPP (W) Light Output on start Action
Output voltage (U-SET) that the group sets.
Current limit (I-SET) that the group sets. Above this current the supply goes to CC mode and lowers the voltage.
Over-voltage protection. If the output voltage goes above this value, the supply switches the output off and shows OVP.
Over-current protection. If the output current goes above this value, the supply switches the output off and shows OCP.
Over-power protection. If the output power goes above this value, the supply switches the output off and shows OPP.
Display brightness that the group sets, from 0 (dark) to 5 (bright).
Output state after power on. "yes" means that the output switches on as soon as the supply starts with this group. Use it with care.
